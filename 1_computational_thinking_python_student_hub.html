13. Conditional Statements

Conditions allow a program to make decisions.

1. if

mark = 75 if mark >= 50: print("Pass")

2. if-else

age = 20 if age >= 18: print("Adult") else: print("Minor")

3. if-elif-else

mark = 82 if mark >= 90: grade = "A+" elif mark >= 75: grade = "A" elif mark >= 50: grade = "B" else: grade = "F" print(grade)

4. Nested if

age = 20 citizen = True if age >= 18: if citizen: print("Eligible")

5. Compound conditions

age = 25 salary = 30000 if age >= 21 and salary >= 25000: print("Eligible") if age < 18 or salary < 15000: print("Check criteria") if not(age < 18): print("Adult")

6. Ternary / Conditional Expression

mark = 65 result = "Pass" if mark >= 50 else "Fail" print(result)
Real-world practice: Build decisions for student grades, login validation, voting-age checks, electricity billing and ticket pricing.
🔁

14. Looping Constructs

Loops repeat a block of code.

1. for loop

for i in range(1, 6): print(i)

2. for over a string

for ch in "PYTHON": print(ch)

3. for over a list

names = ["Anu", "Bala", "Cathy"] for name in names: print(name)

4. while loop

count = 1 while count <= 5: print(count) count += 1

5. Nested loops

for row in range(1, 4): for col in range(1, 4): print(row, col)

6. break

for i in range(1, 10): if i == 5: break print(i)

7. continue

for i in range(1, 6): if i == 3: continue print(i)

8. pass

for i in range(3): pass
range()range(stop), range(start, stop), range(start, stop, step)
Loop controlbreak stops; continue skips; pass does nothing.

15. Functions & Parameter Passing

Functions make programs reusable, organized and easier to test.

1. Built-in functions

print("Hello") name = len("Python") number = int("25") print(name, number)

2. User-defined function

def greet(): print("Welcome") greet()

3. Function with parameters

def add(a, b): return a + b print(add(10, 20))

4. Positional arguments

def student(name, age): print(name, age) student("Anu", 20)

5. Keyword arguments

student(age=20, name="Anu")

6. Default parameter

def greet(name="Student"): print("Hello", name) greet() greet("Anu")

7. Multiple return values

def calculate(a, b): return a + b, a * b total, product = calculate(5, 4)

8. Variable-length arguments

def total(*numbers): return sum(numbers) print(total(10, 20, 30))
Key distinction: A parameter appears in the function definition; an argument is the value supplied during the function call.

16. Basic Debugging Techniques

Debugging is the systematic process of finding and fixing program errors.

Syntax errorPython cannot understand the program structure.
if x > 5 print(x)
Runtime errorAn error occurs while the program runs.
x = 10 / 0
Logical errorThe program runs but gives the wrong answer.
# Intended: area = length * width area = length + width
Name / Type errorsCommon examples include using an undefined variable or incompatible data types.

Debugging workflow

Reproduce
→
Read Error
→
Locate
→
Fix
→
Retest

Useful techniques

Read tracebackStart from the last line and inspect the reported location.
Print debuggingDisplay intermediate values to understand what is happening.
Test small piecesIsolate one function or block at a time.
Use meaningful namesClear names make logical problems easier to find.
